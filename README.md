# TODO – Kanban Based Task Management App

TODO is a mobile-focused task management application built using **Flutter** that follows a **Kanban workflow**.  
It helps users plan, track, and manage tasks efficiently using drag-and-drop interactions, calendar scheduling, and real-time status updates.

---

## 🚀 Key Features

- **Kanban Board Model**
  - Tasks are organized into **To Do**, **In Progress**, and **Done**
  - Users can drag and move tasks between stages smoothly (mobile-friendly)

- **Task Creation & Management**
  - Create tasks with:
    - Task title
    - Description
    - Start date & end date
    - Start time & end time
  - Edit and delete tasks anytime

- **Calendar Integration**
  - Tasks are marked on the calendar using their **due dates**
  - Task status is visually reflected on the calendar
  - Helps users track deadlines effectively

- **Task Alerts & Scheduling**
  - Calendar-based task reminders
  - Clear visibility of upcoming and overdue tasks

- **Time & Duration Tracking**
  - Automatic calculation of task duration
  - Tracks start time, end time, and total time spent
  - Useful for productivity analysis

- **Search & Filtering**
  - Quickly search tasks by title
  - Easily manage large task lists

- **Mobile-First Experience**
  - Designed mainly for mobile users
  - Intuitive drag-and-drop gestures for task movement

## 🛠️ Tech Stack

- **Flutter** – Cross-platform UI development

- **Provider** – State management
- **MVC Architecture** – Clean and scalable project structure

---

## 🏗️ Architecture

The application follows the **MVC (Model–View–Controller)** pattern:
- **Model** – Handles task data and business logic
- **View** – UI screens and widgets
- **Controller** – Manages interactions between UI and data

This ensures better code maintainability and scalability.
